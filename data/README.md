# 正式题库整理底稿

当前目录中的 `formal-idioms-draft.csv` 和 `formal-questions-draft.csv` 是正式题库的整理底稿，不是已经完成审校的官方数据。

已生成的大批量底稿：

- `formal-500-idioms.csv`：500 条来自公开成语数据库的成语资料。
- `formal-200-questions.csv`：基于上述成语释义和例句改编的 200 道原创语境题，可直接导入后台。
- `formal-dataset-source.txt`：数据来源、许可证、生成日期和审核边界。

整理原则：

- 成语资料按《现代汉语词典》（第7版）对应词条建立来源记录，发布前逐条核对。
- 题目为原创语境训练题，不冒充官方真题。
- 每条题目需要确认题干、四个选项、唯一正确答案、解析和来源说明。
- `待校审` 改为 `已校审` 前，不建议批量发布到正式环境。
- 官方真题需要另外记录考试年份、试卷名称、题号和合法来源，不与原创训练题混用。
- 自动二审只检查字段完整、四字词、拼音、重复项、选项唯一性和答案格式，不等于人工语义终审。
